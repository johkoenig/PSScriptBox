# Contributing

Contributions are welcome. Open an issue before making a substantial or behavior-changing contribution so its scope can
be discussed.

## Guidelines

- Keep changes focused, preserve user data, and follow the detailed repository conventions in [AGENTS.md](AGENTS.md).
- Keep English and German user documentation aligned, and add or update tests for behavior changes.
- Add your own name or approved reference to the `Contributors` section of each code file you contribute to.
  See [AGENTS.md](AGENTS.md) for header format and placement; include contact details only with explicit approval.

## AI-assisted work

AI use is welcome and encouraged, especially for standardization, deriving tests, documentation, and review. Vibe coding
is permitted within reason, but review, understand, and validate generated changes before submitting them; you remain
responsible for your PR. Do not share confidential information, credentials, or secrets with AI tools.

## Before submitting

Run the relevant tests and review your changes with `git diff` and `git diff --check`. See [AGENTS.md](AGENTS.md) for
the full validation requirements.

## Pull requests

Describe the user-visible change, implementation details, and validation performed. Call out limitations or behavior
changes.
